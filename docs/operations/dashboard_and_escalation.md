# Operations & Escalation Policies

Operations Managers are empowered to handle system failures and disputes seamlessly.

## Escalation Policy
1. **Donation Published:** Active timer starts.
2. **2-Hours Left (At Risk):** If unclaimed, system triggers background event logging a "Donation At Risk" alert and notifies nearby verified recipient organizations.
3. **Deadline Passed (Expired):** Status changes to `EXPIRED`. Donor and logistics workers are notified. Donation becomes permanently unclaimable.
